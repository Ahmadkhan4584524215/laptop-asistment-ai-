💻 Laptop AI Specs & Performance Analyzer

An interactive Streamlit web application powered by Gemini Flash that instantly extracts core hardware specifications, evaluates gaming and workstation performance, analyzes price variations across models, and compares laptops side-by-side.

🚀 Features

Detailed Hardware Breakdown: Extracts CPU, GPU, RAM, storage type/capacity, battery life, display resolution, refresh rate (Hz), panel type, and available ports.

Performance Scoring: Evaluates real-world performance for gaming and professional workstations.

Model & Price Comparison: Outlines different configurations/sub-models and their estimated pricing tiers.

Head-to-Head Comparison: Compare two laptops side-by-side for gaming and workstation tasks.

🛠️ Installation & Local Setup

Clone or Download this repository.

Install dependencies:

pip install -r requirements.txt


Run the Streamlit app:

streamlit run app.py


Enter your Google Gemini API Key in the sidebar to start analyzing!

📤 How to Push to GitHub

Initialize Git in your project folder:

git init


Stage and commit files:

git add .
git commit -m "Initial commit: Laptop AI Analyzer app"


Link to your GitHub repository and push:

git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
git push -u origin main


☁️ How to Deploy on Streamlit Community Cloud

Go to share.streamlit.io and log in with GitHub.

Click New app.

Select your GitHub repository, main branch, and set main file path to app.py.

Click Deploy!
